# SOLANA SWING BOT · V1 (DEMO)

Скринер токенов Solana в фазе накопления и приложение для спотовой свинг-торговли.
V1 — **демо-контур**: исполнение виртуальное, стартовый баланс $500, транзакции в блокчейн
не отправляются. Фьючерсная логика прежнего автотрейда удалена целиком.

ТЗ, контракт API и логика движка — `docs/PLAN-V1.md` (читать первым).
Замороженный контракт между сервером и клиентом — `shared/types.ts`.
Установка на сервер и команда обновления — `docs/DEPLOY.md`.

## Из чего состоит

- `server/` — данные и логика: воронка скринера (слои 1–5), демо-движок исполнения
  (издержки, Free Riding, time-stop, слив ликвидности), HTTP API, SQLite. Node 24 запускает
  TypeScript нативно, поэтому сборки нет и зависимостей нет.
- `src/` — интерфейс: лента сигналов, карточка монеты с графиком и терминалом, позиции,
  аналитика, профиль с ключами и настройками скринера. React + Vite + Tailwind.

## Запуск

```bash
npm install
cp .env.example .env      # DATA_MODE=mock — работает без ключей и без сети
npm run dev:all           # сервер демо-контура + интерфейс одной командой
```

Интерфейс: http://localhost:5178 · API: http://127.0.0.1:8790 (в dev-режиме Vite проксирует `/api`).

Порознь: `npm run server` и `npm run dev`.

### Как на сервере

`npm ci && npm run build && node server/index.ts` — один процесс отдаёт и интерфейс из `dist/`,
и API по одному адресу. Служба systemd, тоннель и команда обновления — `docs/DEPLOY.md`.

### Режим mock ускорен

Виртуальные часы идут быстрее реальных: каждый цикл обслуживания (60 с) двигает мир на
`demo.tick_minutes` (по умолчанию 360 — шесть виртуальных часов, то есть около 15 виртуальных
суток за реальный час). Так за один вечер видно, как позиция доходит до +100%, срабатывает
Free Riding, истекает time-stop и просаживается ликвидность. Скорость меняется ползунком
в «Профиле».

## Проверки

```bash
node --test server/tests/    # воронка, движок, издержки, гонки, ключи, роуты
npx tsc -b --noEmit          # типы клиента
npm run build                # сборка интерфейса
```

## Ключи и режимы

`DATA_MODE=mock` — синтетика, ключи не нужны. `DATA_MODE=live` — реальные DexScreener,
RugCheck, Helius, Jupiter и Gemini; ключи вводятся в разделе «Профиль» и сохраняются в `.env`
(в репозиторий не попадают, значение кошелька шифруется).

Сервер слушает только `127.0.0.1`. **Аутентификации в V1 нет** — выносить наружу (тоннель, публичный
сервер) можно лишь после того, как она появится: сейчас доступ к ключам и кошельку получит каждый,
кто дотянется до порта.
