# Адрес бота для веб-версии.
#
# Приложение читает этот файл при старте, когда адреса нет ни в ссылке, ни в
# памяти браузера, — чтобы поднять себя само, а не спрашивать у человека
# «укажите адрес сервера».
#
# Одна строка: публичный HTTPS-адрес API автотрейд-бота. Взять его можно
# командой /web в боте. Меняется он при рестарте cloudflared-тоннеля; тогда
# обновите файл одной командой — её подхватят сразу все устройства:
#
#   bash tools/set_api.sh https://xxxx-yyyy.trycloudflare.com
#
# Пока строки нет, приложение спросит адрес на экране входа — это рабочий, но
# неудобный путь.
